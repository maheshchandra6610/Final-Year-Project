This project details the development of a real-time **Malicious Network Traffic Classification system** built upon a **Hybrid Neural Network (HNN)** architecture. Leveraging the comprehensive **CICIDS-2017 dataset**, the system effectively simulates Intrusion Detection and Prevention (IDS/IPS) use cases by analyzing network flow features. Through meticulous data processing and model tuning, the HNN achieved a high-performance validation, demonstrating **99% accuracy** in distinguishing between benign and various categories of malicious network traffic, proving its effectiveness for advanced threat detection.
